# USER GUIDE
## SISTEM INFORMASI PERPUSTAKAAN

### 1. Pendahuluan

User Guide merupakan panduan penggunaan Sistem Informasi Perpustakaan yang dibuat untuk membantu pengguna memahami cara mengoperasikan aplikasi. Panduan ini menjelaskan fungsi utama sistem dan langkah-langkah penggunaannya.

### 2. Tujuan

Panduan ini bertujuan untuk:
1. Membantu pengguna memahami fungsi aplikasi.
2. Memberikan petunjuk penggunaan fitur sistem.
3. Mempermudah pengelolaan data perpustakaan.
4. Mengurangi kesalahan dalam penggunaan aplikasi.

### 3. Panduan Penggunaan Sistem

#### 3.1 Login

1. Buka halaman Sistem Informasi Perpustakaan melalui browser.
2. Masukkan email dan password yang telah terdaftar.
3. Klik tombol Login.
4. Setelah berhasil, pengguna akan diarahkan ke halaman sesuai hak aksesnya.

#### 3.2 Dashboard

Dashboard merupakan halaman utama yang menampilkan informasi dan menu pengelolaan perpustakaan.

#### 3.3 Pengelolaan Data Buku

1. Buka menu data buku.
2. Lihat daftar buku yang tersedia.
3. Tambahkan, ubah, atau hapus data buku sesuai hak akses pengguna.

#### 3.4 Pengelolaan Data Anggota

1. Buka menu data anggota.
2. Periksa daftar anggota perpustakaan.
3. Tambahkan atau perbarui data anggota sesuai kebutuhan.

#### 3.5 Peminjaman Buku

1. Buka menu peminjaman.
2. Pilih anggota yang melakukan peminjaman.
3. Pilih buku yang akan dipinjam.
4. Simpan transaksi peminjaman.

#### 3.6 Pengembalian Buku

1. Buka menu pengembalian.
2. Cari data transaksi peminjaman.
3. Pilih transaksi yang akan dikembalikan.
4. Simpan proses pengembalian.

### 4. Penutup

Dengan adanya panduan ini, diharapkan pengguna dapat memahami dan mengoperasikan Sistem Informasi Perpustakaan dengan lebih mudah. Pengguna disarankan mengikuti langkah-langkah yang telah dijelaskan agar penggunaan sistem berjalan dengan baik.
